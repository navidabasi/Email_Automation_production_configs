Email Automation

Email Automation is a desktop application that connects to Gmail and/or IMAP to extract data from PDF attachments, transform it into structured fields, and export the results to local Excel files or Google Sheets.

What the app does

  • Connects to Gmail API and/or IMAP
  • Extracts PDF text and custom fields using regex rules
  • Exports structured results to Excel
  • Optionally syncs results to Google Sheets
